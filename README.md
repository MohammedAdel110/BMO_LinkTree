# ONLYBMO 🎮🥭

> Pixel streams · mango doodles · late-night vibes

An interactive retro pixel-art link hub and aesthetic bio page featuring BMO from Adventure Time, an ambient CRT loop, synthesized 8-bit Web Audio chiptunes, and quick links.

## ✨ Features

- **CRT Pixel Room Video**: Ambient looping pixel-art video with custom sound toggle.
- **Pixel BMO Avatar**: Transparent pixel-art BMO with tactile hover lift and interactive click bounce.
- **Synthesized 8-Bit Audio**: Retro Game Boy audio synthesized in real time via the Web Audio API.
- **Responsive Social Hub**:
  - Instagram (dual split card: Main `@amer4verse` & Art `@mangoscribble`)
  - YouTube (`@onlybmo`)
  - Kick (`@onlybmo`)
  - Discord Community
  - TikTok (`@onlybmo_`)
  - Streamlabs Mango Tips
- **Ambient Visuals**: Animated CSS particle sparks, ambient glowing orbs, and CRT scanlines.

## 🚀 Quick Start

Run a local HTTP server:

```bash
# Using Python
python -m http.server 8765

# Or using Node
npx serve .
```

Open [http://localhost:8765](http://localhost:8765) in your browser.
